读取本机 WorkBuddy Desktop 的 passToken。请先登录 Desktop，再完全退出（它会锁 cookie 库），然后点检测。
手动导入（手机 / 无 Desktop 环境）
从电脑上的 %LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info 复制 accessToken / refreshToken / uid 粘贴。
修改后浏览器会重新弹出登录框。落盘为加密密文。
默认开启。跳过 WorkBuddyML 格式说明书，走原生 tools/tool_calls（Desktop 推荐）。
开启=压缩摘要，关闭=滑动窗口裁剪。阈值均为 80%。
调用示例：
curl http://127.0.0.1:8080/v1/chat/completions -H "Authorization: Bearer sk-workbuddy" -H "Content-Type: application/json" -d '{"model":"hy4-preview","messages":[{"role":"user","content":"hi"}]}'
模型：hy4-preview · hy3
